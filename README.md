# 📅 Secretary Bot (سكرتارية - إدارة تقويم جوجل بالذكاء الاصطناعي)

بوت تيليجرام شخصي (لمستخدم واحد فقط) يفهم أوامر طبيعية بالعربي (نصية أو صوتية)
ويحوّلها لعمليات على Google Calendar: إضافة/حذف/تعديل/ترحيل مواعيد، مع تصنيف
تلقائي للفئة (شغل، تقني، مذاكرة...) وكشف تعارضات المواعيد، ورسالة صباحية يومية
فيها الطقس وأجندة اليوم.

## المتغيرات (`.env`)

| المتغير | مطلوب | الوصف |
|---|---|---|
| `SECRTARYA_BOT_TOKEN` | ✅ | توكن البوت من @BotFather |
| `TELEGRAM_CHAT_ID` | ✅ | رقمك على تيليجرام (البوت شخصي، مستخدم واحد فقط) |
| `GEMINI_API_KEY` | ✅ | من [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |
| `GOOGLE_CALENDAR_ID` | ✅ | إيميلك أو ID تقويم من إعدادات Google Calendar |
| `MODEL` / `MODEL_V` | ❌ | موديلات Gemini للنص/الصوت (افتراضي `gemini-1.5-flash`) |
| `MORNING_MESSAGE_HOUR/MINUTE` | ❌ | ميعاد الرسالة الصباحية (افتراضي 7:00 بتوقيت القاهرة) |
| `GOOGLE_CREDENTIALS_JSON` / `GOOGLE_TOKEN_JSON` | ❌ | بديل لملفي `credentials.json`/`token.json` كنص JSON مباشر في متغير بيئة |

## ⚠️ ملاحظة أمان مهمة
ملف **`token.json`** المرفق هو نفسه ملف OAuth الحقيقي اللي كان شغّال بيه البوت
الأصلي (فيه `refresh_token` و`client_secret` فعليين يعطيان وصولاً كاملاً
لتقويم جوجل الخاص بصاحب الحساب). تم نسخه كما هو عشان البوت يفضل شغّال بدون
إعادة تسجيل دخول. **لا ترفع هذا الملف لأي مكان عام (GitHub عام مثلاً)** —
`.gitignore` هنا مستبعِده افتراضياً. لو عايز تدوّر التوكن، احذف الملف وشغّل
البوت مرة على جهازك (مش على Railway) عشان يفتح المتصفح لتسجيل دخول جديد،
ثم ارفع `token.json` الجديد يدوياً أو حطه في `GOOGLE_TOKEN_JSON`.

## التشغيل

**محلياً:**
```bash
cp .env.example .env      # واملأ القيم
pip install -r requirements.txt
python bot.py
```

**Docker:**
```bash
docker build -t secretary-bot .
docker run -d --restart always --env-file .env \
  -v $(pwd)/token.json:/app/token.json secretary-bot
```

**Railway:** ارفع المجلد كـ Service مستقل، أضف المتغيرات من *Variables*.
بما إن Railway مالوش تخزين دائم بدون Volume، الأسهل هو حط محتوى `token.json`
في متغير `GOOGLE_TOKEN_JSON` بدل الاعتماد على الملف (الكود بيدعم الاتنين).

## ملاحظات تقنية / تحسين الاستهلاك
- لا نماذج AI محلية — كل الذكاء عبر Gemini API الخارجي (نص وصوت).
- استدعاءات Google Calendar/Gemini/الطقس كلها متزامنة (blocking) لكنها قصيرة
  ومحدودة بأوامر المستخدم الفعلية (بوت شخصي بمعدل استخدام منخفض)، فتأثيرها على
  استهلاك CPU وقت الخمول يكاد يكون معدوماً.
- الجدولة (الرسالة الصباحية) عبر APScheduler مرة واحدة يومياً فقط.
- رسائل الصوت تُحمَّل لملف مؤقت ثم تُحذف مباشرة بعد المعالجة.

## التكلفة التقديرية على Railway (24/7 لمدة 30 يوم)
بصمة مشابهة لبوت Azkar وقت الخمول (بوت شخصي، رسائل قليلة يومياً، لا معالجة
ملفات كبيرة) لكن مع مكتبات Google الإضافية (`google-api-python-client` وغيرها)
اللي بتزود الـ RAM الأساسي شوية:
~55-60MB RAM، ~0.0005 vCPU خمول → `(0.06×$10) + (0.0005×$20) ≈`
**~$0.61/شهر تقريباً** — على الحافة أو فوق حد $0.6 بهامش بسيط.

**اقتراح لو عايز تقلله**: لو مش محتاج تفريغ الرسائل الصوتية (voice)، احذف
استيراد `handlers/voice_handler.py` من `logic.py` (وشيل `filters.VOICE`
handler) — هيقلل استيراد `google.generativeai` مرتين (نص+صوت) لمرة واحدة،
وهيوفر كام ميجا RAM إضافية تنزل بيك تحت $0.55 بأمان.
